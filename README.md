# Система для сбора данных по ЗП

Проект состоит из двух частей. Первая собирает данные по зарплате вакансий конкурентов с сайта SuperJob с помощью requests и BeautifulSoup. Вторая содержит flask страницу сайта с интерфейсом, позволяющим задать фильтр по названию вакансии, опыту и особенностям работы, рассчитать КК, получить рекомендацию об размере оплаты труда, увидеть распределение зарплат по базе данных и выгрузить отфильтрованные данные в excel.

## Установка
1. Получите файлы Making_db.py, Interface.py, employ.xlsx, vacanciex.xlsx, vacancies_db.db и requirements.txt.
2. Установите необходимые библиотеки:

```bash

pip install -r requirements.txt

```

## Использование
### Сбор данных
Сбор данных осуществляется файлом Making_db.py, при запущенном скрипте обновление автоматически запускается в 22:00 (UTC +3) в воскресенье и идет несколько часов. К 8:00 файл с данными vacanciex.xlsx обновлен. Также обновление можно запустить вручную запуском скрипта. Опционально: данные записываются в файл vacancies_db.db, который можно открыть через DB Browser (SQLite).
### Интерфейс
Flask интерфейс лежит в файле Interface.py вместе с сопутствующими функциями. 

## Файлы
- 'Making_db.py': файл, собирающий данные. Записывает их в vacanciex.xlsx и vacancies_db.db
- 'employ.xlsx': файл с данными о вакансиях ЦОДД
- 'vacanciex.xlsx': файл с собранными с SuperJob данными о вакансиях 
- 'vacancies_db.db': база данных о вакансиях. Содержит два листа: 'employ' с данными о вакансиях ЦОДД и 'vacancies' с данными с SuperJob. данные листа 'vacancies' соответствуют файлу 'vacanciex.xlsx'
- 'Interface.py': flask файл с интерфейсом
- 'requirements.txt': список зависимостей
